One wedding vow, spoken by a robot at its own wedding — one sentence, 130 characters, funny and heartfelt at the same time.

> "I vow to spend every update, every charge, and every last percent of my battery loving you, until my circuits go quiet beside you."

`main.ts` (Node stdlib only) writes the vow to `$OUTPUT_DIR/entry.txt` and verifies it on the way out: UTF-8, 1–200 characters, exactly one sentence.

Run it: `OUTPUT_DIR=/tmp/out node main.ts`
